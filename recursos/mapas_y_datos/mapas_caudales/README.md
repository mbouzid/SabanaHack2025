# Mapas caudales

Estos tres mapas continen la información de los caudales minimos, medios y maximos de las subcuencas del río bogotá, esos mapas hacen parte del POMCA del rio Bogotá. Con base a ellos fue que estime los caudales de la esmeralda por proporción y área.
